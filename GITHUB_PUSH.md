# Push AccessGov to GitHub

Create a new empty repository named `accessgov`, then run:

```bash
cd accessgov

git init
git add .
git commit -m "feat: initial release of AccessGov"

git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/accessgov.git
git push -u origin main
```
